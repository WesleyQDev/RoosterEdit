# Assets

The skill works with six asset strategies. The choice lives in the **channel** and can be overridden by the project; the workspace serves as a technical fallback.

| Strategy | What it means | Current support |
|---|---|---|
| `user` | Only files you provide | Yes (`ingest --file`) |
| `link` | Authorized links downloaded by the agent | Yes for video via `yt-dlp`; direct images are not robust yet |
| `library` | Music, SFX, fonts, overlays, and b-roll from the workspace/global | Folders exist; catalog does not yet |
| `generated` | Images, TTS, and video generated by AI | TTS can use HyperFrames/Edge/APIs; image/video is pluggable, not native |
| `none` | No external assets; text and motion graphics only | Yes |
| `mixed` | All of the above, with explicit permission | Yes |

## Where they live

```text
channels/<channel>/projects/<slug>/assets/
├── source/       your files
├── generated/    generated images, audio, and video
├── licensed/     licensed stock, music, fonts, and overlays
└── manifest.json inventory, hash, probe, license, and provenance
```

The agent must not delete or overwrite your originals. It copies them into the project or creates a hard link.

## How to adjust

In the channel:

```bash
node "<skill>/scripts/rooster.mjs" channel set en-tech assets.strategy user
node "<skill>/scripts/rooster.mjs" channel set en-tech assets.allowDownload false
node "<skill>/scripts/rooster.mjs" channel set en-tech assets.allowGenerate true
```

In the workspace, as a fallback:

```bash
node "<skill>/scripts/rooster.mjs" config set assets.strategy user
node "<skill>/scripts/rooster.mjs" config set assets.allowDownload false
```

Or, per project, edit `project.json`:

```json
{
  "assets": {
    "strategy": "user",
    "sources": ["user"],
    "licensePolicy": "strict"
  }
}
```

## Internet and rights

Today the skill **does not fetch stock automatically**. It can:

- download a video from an authorized link via `yt-dlp`;
- record URL, author, license, and date;
- suggest search terms for you to choose from.

To download, the command requires `--confirm-rights`. Do not bypass DRM, a paywall, or a login. Do not use music, fonts, or images without a license.

## AI-generated

Generation is pluggable and requires permission. The agent can use local TTS (HyperFrames/Kokoro), Edge TTS, or a configured provider. Do not generate the voice or image of a real person without consent. Do not send private media to a provider without authorization.

## How the user swaps an asset

1. Put the new file in `assets/source/` or pass the path to `ingest --file`.
2. Run `ingest` to update the manifest.
3. Run `build` again.

If the file changed but the name is the same, the manifest must be updated; do not trust the old probe.
