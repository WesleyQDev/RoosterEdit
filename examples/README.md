# Examples

Projetos de exemplo planejados. Cada exemplo deve ser pequeno o suficiente para rodar em um laptop e cobrir um caminho diferente do pipeline.

## Planejados

| Exemplo | Cobre |
|---|---|
| `talking-head` | Footage real, transcript, EDL, b-roll, legendas |
| `faceless-explainer` | TTS, HyperFrames, kinetic type, charts |
| `3d-cartoon` | Three.js, Remotion, personagem, música |
| `product-promo` | Screenshots, logo, callouts, música |
| `link-ingest` | yt-dlp, metadata, transcript, corte |

## Regras

- Usar assets livres ou gerados.
- Não commitar vídeos grandes; usar fixtures leves.
- Cada exemplo deve ter um README com o comando exato para reproduzir.
- Cada exemplo deve passar no `check` e no QA básico.

Os exemplos serão criados depois que os adapters de engine estiverem estáveis.
